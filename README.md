## How to add her photos (2 minutes)

1. Put her photo files in this same folder
   Rename them: photo1.jpg, photo2.jpg ... photo6.jpg

2. Open index.html in Notepad/VS Code
   Find this line near the bottom:
   ```
   const PHOTOS=['','','','','',''];
   ```
   Change to:
   ```
   const PHOTOS=['photo1.jpg','photo2.jpg','photo3.jpg','photo4.jpg','photo5.jpg','photo6.jpg'];
   ```

3. Optional — change photo captions too:
   ```
   const CAPTIONS=['a moment i loved','one of my favourites',...];
   ```
   Replace with your own captions for each photo.
